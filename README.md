### 🧠 How I Build AI Systems

- **Agent architecture:** intent routing, multi-agent workflows, tool use, memory, structured outputs, and human-in-the-loop flows.
- **Latency as a requirement:** streaming over SSE, acting on partial outputs, and provider fallback behind a single LLM interface.
- **Observability & evaluation:** tracing every agent step with Langfuse and evaluating answers before they reach users.
- **Model serving:** vLLM/ONNX deployment, profiling with Nsight Systems, and kernel-level tuning when the bottleneck is the GPU.
